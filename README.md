# Викины игры

Коллекция маленьких браузерных игр. Каждая игра — один HTML-файл без внешних зависимостей.

## Игры

### 🌀 Лабиринт — [`labirint/index.html`](labirint/index.html)

1. Создай героя: мальчик или девочка, причёска, цвет волос, кожа, глаза, улыбка, одежда и обувь.
2. Нажми «В лабиринт».
3. Собери все звёзды ⭐, чтобы открыть дверь 🚪, и найди выход.

Управление: стрелки / WASD на компьютере, экранные стрелки или свайпы на телефоне. Esc — пауза.

## Как запустить

Открой `index.html` в браузере или зайди на GitHub Pages:
<https://gritsulyak.github.io/vika_games/labirint/>

## Структура

```
index.html            — главная страница со списком игр
labirint/index.html   — игра «Лабиринт»
```
